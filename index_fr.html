03 — Profil

À propos

Bonjour, je m'appelle Jordi de Leon Chapuis. J'ai commencé à apprendre la programmation en m'inscrivant au grade en Multimédia à l'UOC, que je suis actuellement. Depuis, j'ai créé plusieurs projets from scratch. L'une de mes fiertés est d'avoir réalisé le site web d'une boulangerie locale en Suisse j'ai tout géré moi-même : design, multimédia, développement et mise en ligne. Ce n'est pas quelque chose d'énorme, mais pour moi c'est une étape très importante.

J'essaie d'apprendre quelque chose de nouveau chaque jour. Je me forme actuellement sur le campus mouredev.pro, en approfondissant différents langages de programmation avec un intérêt croissant pour JavaScript et Python.

Je m'intéresse aussi beaucoup à l'intégration de l'IA dans le travail quotidien. J'utilise des outils comme Claude Code pour construire des projets réels, mais toujours selon mon propre jugement en utilisant l'IA comme un allié, sans la laisser tout faire à ma place.

Mon objectif est de travailler comme développeur front-end dans une entreprise où je puisse continuer à progresser, apprendre et devenir un meilleur développeur chaque jour.

Ce que j'apprends

  • JavaScript (DOM, logique, ES6+) sur mouredev.pro
  • Développement d'applications avec Claude Code et le vibe coding
  • Les workflows Git et GitHub
  • Les agents IA appliqués à la programmation
  • Multimédia : design, audio, vidéo (UOC)
  • UX/UI et design d'interfaces
